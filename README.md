# 月森守卫

手机触控塔防小游戏：31 处阵地、8 波敌人、三种守卫，以及升级、回收、月霜、暂停、两倍速与胜负重开。

- `npm install`
- `npm run dev`
- `npm test`
- `npm run build`

## 战斗

游侠弓手拉弓后发箭，冰塔蓄起冰刺，火炮发射后后坐。攻击包含蓄力、发射、弹药飞行、命中和恢复，伤害在命中后结算。弓手、冰塔、火炮的相邻射击间隔约 2.55、3.45、4.6 秒；普通敌人速度为 17.8–23.4，首领为 13（战场坐标单位/秒）。

哥布林有行军、中箭、惊恐、冻僵和倒地动作。三种武器都有真实的沿路击退；敌人分别怕扎、怕冷、怕炸，命中其弱点伤害增加 20%，惊退更远。首领有击退抗性；短暂稳定期防止重复受击造成无限击退。死亡动作保留后再移除，金币只结算一次。

## 屏幕与操作

战场按可用宽高等比缩放，不压扁地图。宽屏旋转地图布局，角色保持直立。支持放大至 180%、触控滑动及一键还原。操作区独立于地图滚动区域，使用动态视口高度及安全区。暂停和切出页面会同时停止行军、蓄力、飞行弹药与反应。

进度仅保留在当前页面，刷新重新开始。音效默认关闭，开启后弓箭、寒冰、火炮使用不同的发射音。

## 验证

`npm test` 覆盖阵地合法性、多个尺寸的横竖屏坐标与等比适配、建造经济、蓄力及延迟命中、三种击退、弱点与首领抗性、冰缓速、炮弹范围伤害、暂停、死亡结算，以及完整八波胜利和失败。画面素材已检查透明度与帧范围；这些自动检查不代表真实设备触控及视觉验收。

WebMCP 在支持 `document.modelContext` 的浏览器注册 `read_defense` 与 `command_defense`，复用游戏规则。接口阵地范围同步扩展至 0–30。当前环境没有可用的 WebMCP 验证上下文，未执行浏览器契约验证。
