# 月森守卫

手机触控合成塔防小游戏：商店、6 格守卫厅、31 处战场阵地与 8 波挑战。保留三种守卫的战斗动作、月霜、暂停、两倍速与胜负重开。

- `npm install`
- `npm run dev`
- `npm test`
- `npm run build`

## GitHub Pages

执行 `npm run build:pages` 生成 `dist-pages/` 静态站点，发布该目录即可。静态入口直接复用现有游戏组件，不依赖服务器；图片和脚本路径兼容 GitHub Pages 仓库子路径。原有 `npm run dev` 与 Sites 构建仍可使用。

## 招募与合成

商店有 3 个货位，初始提供三种 1 级守卫；刷新花费 15 金币，购买价格分别为 60 / 80 / 100。购买只进入守卫厅，不自动上阵。守卫厅最多 6 格，满员购买失败不会扣费。

同种同级的两名守卫免费合成一级，最高 4 级。守卫厅内部、战场内部、守卫厅到战场、战场回守卫厅均可合成；成品留在目标位置。不同种类、等级不符、顶级或无效目标不会移动或扣费。空位允许普通移动，厅内守卫可以一直待命。

使用 Pointer Events 支持鼠标和触控拖放，拖动超出目标或取消后保留原位。点击只选中或查看守卫，换位需要拖动；选中后“合成”寻找伙伴合入当前守卫。数字等级、递增体积、银色盾徽、精锐宝石、传奇金冠与光效区别阶级。伤害每级乘以 2.1，射程每级增加 14。出售返还累计购买价格的 25%，合成不会凭空增值。

## 战斗

游侠弓手拉弓后发箭，冰塔蓄起冰刺，火炮发射后后坐。攻击包含蓄力、发射、弹药飞行、命中和恢复，伤害在命中后结算。弓手、冰塔、火炮的相邻射击间隔约 2.55、3.45、4.6 秒；普通敌人速度为 17.8–23.4，首领为 13（战场坐标单位/秒）。

哥布林有行军、中箭、惊恐、冻僵和倒地动作。三种武器都有真实的沿路击退；敌人分别怕扎、怕冷、怕炸，命中其弱点伤害增加 20%，惊退更远。首领有击退抗性；短暂稳定期防止重复受击造成无限击退。死亡动作保留后再移除，金币只结算一次。

## 屏幕与操作

战场按可用宽高等比缩放，不压扁地图。宽屏旋转地图布局，角色保持直立。支持放大至 180%、触控滑动及一键还原。操作区独立于地图滚动区域，使用动态视口高度及安全区。暂停和切出页面会同时停止行军、蓄力、飞行弹药与反应。

进度仅保留在当前页面，刷新重新开始。音效默认关闭，开启后弓箭、寒冰、火炮使用不同的发射音。

## 验证
